# core-schedule

Расписание занятий и сессии: шаблоны, исключения, экзамены, CalDAV-подписка для студентов и преподавателей.

**Стек:** FastAPI · SQLAlchemy (async) · PostgreSQL  
**Порт:** `8003`  
**БД:** `core_schedule_db` → PgBouncer `pgbouncer-core-schedule`

---

## Доменная область

- Хранение двухнедельных шаблонов расписания по группам
- Применение разовых исключений (`schedule_override`) на конкретные даты
- События сессии: экзамены, зачёты, консультации
- Выдача расписания на произвольный диапазон дат (шаблон + исключения)
- CalDAV-эндпоинты для подписки на `.ics`-календарь
- Административное управление: семестры, аудитории, шаблоны, события, преподаватели
- Кеш преподавателей (`teacher_cache`) — синхронизация UUID из `core-client-info`

## API роуты

Все роуты доступны через gateway с префиксом `/core-schedule`.

### Расписание групп

| Метод | Путь                            | Описание                                                |
| ----- | ------------------------------- | ------------------------------------------------------- |
| `GET` | `/groups`                       | Список всех групп                                       |
| `GET` | `/groups/{group_name}/schedule` | Расписание группы на диапазон дат (шаблон + исключения) |
| `GET` | `/groups/{group_name}/exams`    | Экзамены и зачёты группы в текущей сессии               |
| `GET` | `/groups/{group_name}/template` | Двухнедельный шаблон группы                             |

### Расписание преподавателей

| Метод | Путь                              | Описание                                   |
| ----- | --------------------------------- | ------------------------------------------ |
| `GET` | `/teachers`                       | Список преподавателей (из `teacher_cache`) |
| `GET` | `/teachers/{teacher_id}/schedule` | Расписание преподавателя на диапазон дат   |
| `GET` | `/teachers/{teacher_id}/exams`    | Экзамены преподавателя в сессии            |
| `GET` | `/teachers/{teacher_id}/template` | Двухнедельный шаблон преподавателя         |

### CalDAV

| Метод | Путь                                                 | Описание                                      |
| ----- | ---------------------------------------------------- | --------------------------------------------- |
| `GET` | `/caldav/{token}/groups/{group_name}/calendar.ics`   | `.ics`-файл для подписки группы на расписание |
| `GET` | `/caldav/{token}/teachers/{teacher_id}/calendar.ics` | `.ics`-файл для подписки преподавателя        |

> `{token}` — CalDAV-токен из `core-auth`. Передаётся в URL, не требует JWT-заголовка, содержит токен как in-path параметр.
